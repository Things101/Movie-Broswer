# 🎬 Movie Browser App

A sleek web app that lets users search for movies and view detailed information such as title, release year, genre, runtime, plot, ratings, and more. Powered by the **OMDb API** and built with **React**.

## 🔍 Features

- 🎥 **Search for Movies** by title
- 📄 **View Movie Details** including:
  - Title
  - Year
  - Genre
  - Runtime
  - Plot
  - Poster
  - IMDb Ratings
- ⚡ **Real-Time Search** with responsive UI
- 🧹 **Graceful Error Handling** for missing or invalid movie queries

## 🛠️ Built With

- **React**
- **JavaScript**
- **Axios** for fetching data
- **HTML & CSS**
- **OMDb API** – [http://www.omdbapi.com](http://www.omdbapi.com)
